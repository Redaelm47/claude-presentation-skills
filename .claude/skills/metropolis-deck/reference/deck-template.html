Contexte · 2017

Les limites des
RNN & LSTM

  • Calcul séquentiel : l'état ht dépend de ht−1 : aucune parallélisation dans la séquence.
  • Dépendances longues : le signal se dilue sur de grandes distances.
  • Coût croissant : temps et mémoire suivent la longueur des phrases.
  • Convolutions (ByteNet, ConvS2S) : atténuent, sans supprimer le problème.

Le problème · 1/2

Le traitement
séquentiel

  • O(n) opérations séquentielles : chaque état attend le précédent.
  • Chemin long : relier deux mots distants coûte O(n) étapes.
  • Gradient fragile : plus le chemin est long, plus les dépendances sont dures à apprendre.

Le problème · 2/2

Rompre avec
la récurrence

  • GPU sous-exploités : pas de parallélisme à l'intérieur d'une séquence.
  • L'idée clé : remplacer la récurrence par l'attention : un chemin O(1) entre toute paire de mots.
  • « Attention Is All You Need » : plus de récurrence, plus de convolution.

Query, Key,
Value

  • Score : compatibilité Query · Key entre tous les mots.
  • Poids : softmax des scores → somme pondérée des Values.

Mécanisme

Scaled
dot-product

  • Division par √dk : évite des produits scalaires trop grands.
  • Sans mise à l'échelle : le softmax sature, les gradients s'évanouissent.
  • Masque optionnel : dans le décodeur, bloque l'accès au futur.

Mécanisme

Multi-head
attention

  • h = 8 têtes d'attention calculées en parallèle.
  • dk = dv = 64 : soit dmodel / h.
  • Chaque tête apprend un sous-espace de relations différent.
  • Concaténation → projection linéaire finale.
